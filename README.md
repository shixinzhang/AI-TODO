包含：
- 待办 AI 拆解

- ...

各子项目独立依赖与端口，可分别启动。

## 子项目一览

| 路径 | 功能 | 默认端口 | 启动方式 |
|------|------|----------|----------|
| [todo-and-chat](./todo-and-chat/) | 待办 + 多模态 AI 对话 | **3000** | 见下方 |
| [rag](./rag/) | RAG 文档上传与问答 | **4000** | 见下方 |

---

###  todo-and-chat

**路径**：`todo-and-chat/`

**功能**：待办事项管理 + 多模态 AI 对话。支持任务 CRUD（Supabase）、流式对话、图片/视频生成、提示词优化、语音转写等；前端为 Next.js + Tailwind，含长期/短期记忆与用户画像。

**启动方式**：

```bash
cd todo-and-chat
npm install   # 首次需安装依赖
npm run dev -- -p 3000
```

**运行端口**：`3000`（本地访问：<http://localhost:3000>）

**环境**：复制 `env.example` 为 `.env.local`，配置 Supabase 与 AI 相关变量；数据库需执行 `supabase-schema.sql`。详见 [todo-and-chat/API_DOCUMENTATION.md](./todo-and-chat/API_DOCUMENTATION.md)。

---

### RAG

**路径**：`rag/`

**功能**：RAG（检索增强生成）文档问答。支持 PDF/CSV/TXT 等上传、文档切分与向量化、基于文档的对话与溯源；技术栈为 Next.js + LangChain，可选 Chroma / Milvus 等向量库。

**启动方式**：

```bash
cd rag
npm install   # 首次需安装依赖
npm run dev -- -p 4000
```

**运行端口**：`4000`（本地访问：<http://localhost:4000>）

**环境**：按需配置向量库与嵌入模型（见 `rag/README.md` 或项目内说明）。

---

### 同时运行多个子项目

- todo-and-chat：`npm run dev -- -p 3000` → http://localhost:3000  
- rag：`npm run dev -- -p 4000` → http://localhost:4000  

两项目端口不同，可同时启动，互不影响。
